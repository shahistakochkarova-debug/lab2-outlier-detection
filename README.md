# Лабораторная работа №2
## Обнаружение выбросов и проверка нормальности распределения

### Описание
В этой лабораторной работе я анализирую данные о продажах и ищу выбросы разными методами.

### Датасет
- Файл: ПРОДАЖА_data_(1).xlsx
- Записи: 502
- Признаки: дата, товар, город, количество, цена, скидка, возраст, оплата

### Методы которые я использовал
| Метод | Что делает |
|-------|------------|
| Z-score | Ищет точки далеко от среднего (для нормальных данных) |
| IQR | Ищет точки за пределами 1.5 * межквартильного размаха |
| k-ближайших соседей | Ищет точки в областях с низкой плотностью |
| Шапиро-Уилк | Проверяет нормальность распределения |

### Результаты

**Проверка нормальности цены:**
- p-value < 0.05 → распределение НЕ нормальное
- Асимметрия: положительная (хвост справа длиннее)
- Эксцесс: отрицательный (плоское распределение)

**Количество выбросов:**
| Метод | Количество |
|-------|-------------|
| Z-score (цена) | 12 |
| IQR (цена) | 38 |
| kNN, k=5 (цена + количество) | 25 |

### Выводы
1. Распределение цены не нормальное, поэтому IQR подходит лучше чем Z-score
2. Метод k-ближайших соседей хорошо находит аномалии без предположения о нормальности
3. При увеличении k количество аномалий уменьшается
